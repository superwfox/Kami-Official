DingTalk-JinBuTi.ttf

Font family: DingTalk JinBuTi (钉钉进步体).
Converted from the user-provided DingTalk-JinBuTi(1).woff2 to an un-subsetted
TrueType font, retaining all glyphs and the original font metadata.
Java2D cannot load WOFF2 directly. The renderer loads this bundled font rather
than depending on fonts installed on the host.
